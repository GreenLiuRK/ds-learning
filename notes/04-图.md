# 图

## 一、基本概念

- **有向图 / 无向图**：边是否有方向
- **度**：无向图中与顶点相连的边数；有向图分**入度**和**出度**
- **路径**：顶点序列；**回路**：起点终点相同
- **连通图**：任意两点可达（无向）；**强连通图**：有向图任意两点互相可达
- **生成树**：n 个顶点的连通图，含 n-1 条边

**边的数量关系**：
- 无向完全图：n(n-1)/2 条边
- 有向完全图：n(n-1) 条边
- 无向图所有顶点度数之和 = 2 × 边数

## 二、存储结构

| 方式 | 空间 | 适合 | 找邻接点 |
| --- | --- | --- | --- |
| 邻接矩阵 | O(n²) | 稠密图 | O(n) |
| 邻接表 | O(n+e) | 稀疏图 | O(度) |
| 十字链表 | O(n+e) | 有向图 | 兼顾入度出度 |
| 邻接多重表 | O(n+e) | 无向图 | 边操作方便 |

```c
// 邻接矩阵
typedef struct {
    int vertex[MAXV];         // 顶点表
    int edge[MAXV][MAXV];     // 邻接矩阵
    int vexnum, arcnum;
} MGraph;
```

## 三、遍历

| 遍历 | 数据结构 | 用途 |
| --- | --- | --- |
| DFS（深度优先） | **栈**（递归） | 连通性、拓扑排序、回溯 |
| BFS（广度优先） | **队列** | 最短路径（无权图）、层次 |

两者时间复杂度都是：邻接矩阵 **O(n²)**，邻接表 **O(n+e)**。

## 四、最小生成树（MST）

| 算法 | 思路 | 复杂度 | 适合 |
| --- | --- | --- | --- |
| **Prim** | 从一点出发，每次加入最近的顶点 | O(n²) | 稠密图 |
| **Kruskal** | 边排序，用并查集，不形成环就加入 | O(e log e) | 稀疏图 |

性质：MST 的边权之和唯一，但**树的形态可能不唯一**。

## 五、最短路径

| 算法 | 解决什么 | 复杂度 | 限制 |
| --- | --- | --- | --- |
| **Dijkstra** | 单源最短路 | O(n²) / 堆优化 O(e log n) | **不能有负权边** |
| **Floyd** | 多源最短路 | O(n³) | 可以有负权（不能有负环） |
| **Bellman-Ford** | 单源 + 判负环 | O(ne) | 可有负权 |
| **SPFA** | Bellman-Ford 的队列优化 | 平均快，最坏 O(ne) | 可有负权，可能被卡 |

Dijkstra 的核心：每次从未确定的点里选 `dist` 最小的，加入已确定集合，用它松弛邻居。

## 六、拓扑排序

**前提：有向无环图（DAG）**。

做法（Kahn 算法）：
1. 统计所有顶点入度；
2. 入度为 0 的入队；
3. 出队一个，输出，把它指向的顶点入度减 1；
4. 减到 0 的入队；
5. 若输出顶点数 < 总数，说明有环。

应用：课程安排、任务调度、依赖解析。

## 七、关键路径

- **AOV 网**：顶点表示活动，边表示先后关系 → 拓扑排序
- **AOE 网**：边表示活动，权值表示持续时间 → 关键路径
- 关键路径 = **最长路径**，决定整个工程的最短工期
- 关键活动：最早开始时间 == 最晚开始时间

## 八、易错点

1. 邻接矩阵的对称性：无向图对称，有向图不一定；
2. Dijkstra 不能处理负权边——这是选择题常考陷阱；
3. 邻接表存无向图，一条边要存两次（空间 2e）；
4. 拓扑排序的结果**不唯一**；
5. 连通分量针对无向图，强连通分量针对有向图，别混。

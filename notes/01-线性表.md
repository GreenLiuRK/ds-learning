# 线性表

## 一、基本概念

线性表是 n 个数据元素的有限序列，元素之间是**一对一**的关系：除第一个元素外每个元素有且只有一个前驱，除最后一个元素外每个元素有且只有一个后继。

两种存储方式：

| 存储方式 | 特点 | 随机访问 | 插入/删除 |
| --- | --- | --- | --- |
| 顺序表 | 逻辑相邻，物理也相邻 | O(1) | O(n)，要移动元素 |
| 链表 | 逻辑相邻，物理不一定相邻 | O(n) | O(1)（已定位前驱时） |

## 二、顺序表

### 结构定义

```c
#define MAXSIZE 100
typedef struct {
    ElemType data[MAXSIZE];   // 静态分配
    int length;
} SqList;
```

动态分配版本：`ElemType *data;` + `malloc`。

### 关键操作

**插入**（在第 i 个位置插入，i 从 1 开始）

```c
// 合法范围：1 <= i <= length + 1
for (j = length - 1; j >= i - 1; j--)
    data[j + 1] = data[j];   // 从后往前挪
data[i - 1] = e;
length++;
```

**删除**（删除第 i 个）

```c
// 合法范围：1 <= i <= length
for (j = i; j < length; j++)
    data[j - 1] = data[j];   // 从前往后挪
length--;
```

### 复杂度

- 插入：平均移动 n/2 个元素 → **O(n)**
- 删除：平均移动 (n-1)/2 个元素 → **O(n)**
- 按位查找：**O(1)**

## 三、链表

### 单链表（带头结点）

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

头结点的作用：让**空表和非空表**、**表头插入和表中间插入**的代码统一，不用特判。

### 插入：先接后、再接前

```c
s->next = p->next;   // 顺序不能反
p->next = s;
```

写反了会丢掉 p 后面的整条链——这是最经典的错误。

### 删除

```c
q = p->next;
p->next = q->next;
free(q);
```

### 头插法 vs 尾插法

- **头插法**：每次插在头结点之后，结果是**逆序**（可用来反转链表）
- **尾插法**：维护 tail 指针，结果是**正序**（建表常用）

## 四、顺序表 vs 链表 怎么选

| 场景 | 选择 |
| --- | --- |
| 经常按位置访问 | 顺序表 |
| 频繁插入删除、表长变化大 | 链表 |
| 表长基本固定、以查询为主 | 顺序表 |
| 需要节省空间（不用预留） | 链表 |

## 五、易错点

1. **插入位置 n+1 合法，删除位置 n 合法**，差一位；
2. 顺序表插入必须**从后往前**挪，删除**从前往后**挪；
3. 链表插入两句顺序不能反；
4. 带头结点的链表，遍历从 `L->next` 开始，不是 `L`；
5. 删除结点后要 `free`，否则内存泄漏；
6. 空表判断：顺序表 `length == 0`，链表 `L->next == NULL`。

## 六、经典题

| 题目 | 思路 |
| --- | --- |
| 反转链表 | 头插法 / 三指针 |
| 找中间结点 | 快慢指针，快的走两步 |
| 判断有环 | 快慢指针相遇则有环 |
| 合并两个有序链表 | 双指针，尾插 |
| 删除倒数第 k 个 | 双指针，先走 k 步 |

## 七、复杂度速查

| 操作 | 顺序表 | 链表 |
| --- | --- | --- |
| 按位查找 | O(1) | O(n) |
| 按值查找 | O(n) | O(n) |
| 插入 | O(n) | O(n)（找前驱） |
| 删除 | O(n) | O(n)（找前驱） |
| 空间 | 预分配，可能浪费 | 按需，有指针开销 |

# 栈与队列

## 一、栈（Stack）

**后进先出（LIFO）**，只在栈顶插入和删除。

### 顺序栈

```c
typedef struct {
    ElemType data[MAXSIZE];
    int top;        // 栈顶指针，指向栈顶元素
} SqStack;
```

- 空栈：`top == -1`
- 栈满：`top == MAXSIZE - 1`
- 入栈：`data[++top] = x;`
- 出栈：`x = data[top--];`

### 链栈

用单链表实现，**栈顶放在链表头**，入栈出栈都是 O(1)。

### 应用

| 场景 | 说明 |
| --- | --- |
| 括号匹配 | 左括号入栈，右括号出栈比对 |
| 表达式求值 | 中缀转后缀，再计算 |
| 递归 | 系统栈保存返回地址和局部变量 |
| 函数调用 | 调用栈 |
| 撤销/回退 | 浏览器后退、编辑器撤销 |

## 二、队列（Queue）

**先进先出（FIFO）**，队尾入队，队头出队。

### 循环队列（顺序存储）

```c
typedef struct {
    ElemType data[MAXSIZE];
    int front, rear;     // front 指向队头，rear 指向队尾的下一个
} SqQueue;
```

为了区分**队空**和**队满**，有三种做法：

| 方案 | 队空 | 队满 | 元素个数 |
| --- | --- | --- | --- |
| 牺牲一个单元 | `front == rear` | `(rear+1)%MAXSIZE == front` | `(rear-front+MAXSIZE)%MAXSIZE` |
| 加 size 变量 | `size == 0` | `size == MAXSIZE` | `size` |
| 加 tag 标记 | `front==rear && tag==0` | `front==rear && tag==1` | 计算 |

考试常考第一种，**务必背下这三个公式**。

### 链队列

带头结点的单链表，队头在 `front->next`，队尾用 `rear` 指向。

### 应用

| 场景 | 说明 |
| --- | --- |
| BFS 广度优先搜索 | 树的层序遍历、图的 BFS |
| 任务调度 | 打印队列、消息队列 |
| 缓冲区 | 生产者-消费者 |
| 滑动窗口 | 单调队列优化 |

## 三、双端队列

两端都能插入删除的队列。**输入受限**（只能一端插入）和**输出受限**（只能一端删除）两种变体，考试喜欢考"哪个序列不可能得到"。

## 四、易错点

1. 循环队列的取模运算别漏：`(rear+1) % MAXSIZE`；
2. 入队先判满，出队先判空；
3. 栈的 `top` 初值：指向栈顶元素用 `-1`，指向栈顶下一个用 `0`，两种约定别混；
4. 链栈入栈是**头插**，不是尾插；
5. 递归转非递归，本质是用**自己维护的栈**代替系统栈。

## 五、经典题

| 题目 | 思路 |
| --- | --- |
| 有效的括号 | 栈匹配 |
| 用栈实现队列 | 两个栈，一个进一个出 |
| 用队列实现栈 | 两个队列倒腾 |
| 单调栈：下一个更大元素 | 维护递减栈 |
| 滑动窗口最大值 | 单调队列 |
| 逆波兰表达式求值 | 栈 |

## 六、复杂度

| 操作 | 栈 | 队列 |
| --- | --- | --- |
| 入 | O(1) | O(1) |
| 出 | O(1) | O(1) |
| 取顶/队头 | O(1) | O(1) |

# 排序

## 一、总览（必背表）

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 直接插入 | O(n²) | O(n²) | O(1) | **稳定** |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | **稳定** |
| 快速排序 | O(n log n) | **O(n²)** | O(log n) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | **O(n)** | **稳定** |
| 基数排序 | O(d(n+r)) | 同左 | O(n+r) | **稳定** |

**口诀**：快排最坏 n²、归并要 O(n) 空间、堆排序原地但不稳、稳定的是"插入冒泡归并基数"。

## 二、插入排序

**直接插入**：把当前元素插到前面已排好的序列里。

```c
for (i = 2; i <= n; i++) {
    if (a[i] < a[i-1]) {
        a[0] = a[i];              // 哨兵
        for (j = i-1; a[0] < a[j]; j--)
            a[j+1] = a[j];
        a[j+1] = a[0];
    }
}
```

- 最好情况（已有序）O(n)，最坏（逆序）O(n²)
- 稳定；适合**基本有序**和**数据量小**的场景

**希尔排序**：按增量分组做插入排序，增量逐渐减到 1。

- 时间复杂度与增量序列有关，约 O(n^1.3)
- 不稳定；是**第一个突破 O(n²)** 的算法

## 三、交换排序

**冒泡**：相邻比较，大的往后沉。

```c
for (i = 0; i < n-1; i++) {
    flag = 0;
    for (j = 0; j < n-1-i; j++)
        if (a[j] > a[j+1]) { swap; flag = 1; }
    if (!flag) break;         // 一趟没交换，已经有序
}
```

**快速排序**：选基准（pivot），把比它小的放左边、大的放右边，再递归两边。

```c
void QuickSort(int a[], int low, int high) {
    if (low >= high) return;
    int i = low, j = high, pivot = a[low];
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;
    QuickSort(a, low, i-1);
    QuickSort(a, i+1, high);
}
```

- 平均 O(n log n)，**最坏 O(n²)**（已有序且取第一个做基准）
- 优化：随机基准、三数取中、小区间用插入排序

## 四、选择排序

**简单选择**：每趟选最小的放前面，交换次数少（最多 n-1 次）。

**堆排序**：

1. 建大顶堆（从 n/2 往下调整）
2. 堆顶与末尾交换，堆大小减 1，重新调整

```c
void HeapAdjust(int a[], int k, int n) {
    int temp = a[k];
    for (int i = 2*k; i <= n; i *= 2) {
        if (i < n && a[i] < a[i+1]) i++;      // 取较大的孩子
        if (temp >= a[i]) break;
        a[k] = a[i];
        k = i;
    }
    a[k] = temp;
}
```

- 建堆 O(n)，每次调整 O(log n)，总 O(n log n)
- 空间 O(1)，适合**求前 k 大/小**

## 五、归并排序

分治：把数组一分为二，分别排序，再合并两个有序数组。

```c
void Merge(int a[], int temp[], int low, int mid, int high) {
    int i = low, j = mid+1, k = low;
    while (i <= mid && j <= high)
        temp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid)  temp[k++] = a[i++];
    while (j <= high) temp[k++] = a[j++];
    for (k = low; k <= high; k++) a[k] = temp[k];
}
```

- 稳定，O(n log n)，**需要 O(n) 额外空间**
- 适合**外部排序**和链表排序

## 六、基数排序

按个位、十位、百位……依次分配到 10 个桶里再收集。

- 不比较关键字大小，是**分配式排序**
- 时间复杂度 O(d(n+r))，d 是位数、r 是基数
- 稳定

## 七、怎么选

| 场景 | 推荐 |
| --- | --- |
| 数据量小、基本有序 | 直接插入 |
| 数据量大、要求稳定 | 归并 |
| 数据量大、要求原地 | 堆排序 / 快排 |
| 求前 k 大 | 堆（O(n log k)） |
| 外部排序（内存装不下） | 归并 |
| 整数且范围小 | 计数/基数排序 |

## 八、易错点

1. 快排最坏 O(n²)，不是稳定的；
2. 归并空间 O(n)，不是 O(1)；
3. 堆排序建堆是 O(n) 不是 O(n log n)；
4. 稳定排序只有四个：**插入、冒泡、归并、基数**；
5. 快排递归深度 O(log n)，最坏 O(n)，极端情况会栈溢出。

## 九、经典题

| 题目 | 思路 |
| --- | --- |
| 数组中的第 K 个最大元素 | 快排 partition / 小顶堆 |
| 合并 K 个有序链表 | 优先队列 |
| 排序数组 | 快排 / 归并 |
| 前 K 个高频元素 | 哈希 + 堆 |
| 颜色分类 | 三指针（荷兰国旗） |

# 树与二叉树

## 一、基本术语

- **结点的度**：该结点拥有的子树数
- **树的度**：所有结点度的最大值
- **叶子**：度为 0 的结点
- **层次**：根为第 1 层
- **深度/高度**：结点的最大层次
- **森林**：m 棵互不相交的树的集合

## 二、二叉树的性质（必背）

1. 第 i 层最多有 **2^(i-1)** 个结点
2. 深度为 k 的二叉树最多有 **2^k - 1** 个结点
3. 叶子数 n0 与度为 2 的结点数 n2 满足：**n0 = n2 + 1**
4. 完全二叉树中，结点 i 的左孩子是 **2i**，右孩子是 **2i+1**，父结点是 **i/2**
5. n 个结点的完全二叉树高度为 **⌊log₂n⌋ + 1**

> 第 3 条是选择题高频考点，推导：n = n0 + n1 + n2，边数 = n - 1 = n1 + 2n2。

## 三、存储结构

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 顺序存储 | 完全二叉树 | 用数组，下标对应位置；非完全二叉树会浪费大量空间 |
| 链式存储 | 一般二叉树 | 二叉链表：`lchild | data | rchild` |

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

## 四、遍历（核心）

| 遍历 | 顺序 | 用途 |
| --- | --- | --- |
| 先序 | 根 → 左 → 右 | 复制树、序列化 |
| 中序 | 左 → 根 → 右 | **二叉排序树得到有序序列** |
| 后序 | 左 → 右 → 根 | 释放树、求表达式 |
| 层次 | 逐层，用队列 | BFS |

### 递归写法（先序为例）

```c
void PreOrder(BiTree T) {
    if (T == NULL) return;
    visit(T);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}
```

中序、后序只是把 `visit` 换个位置。

### 非递归（用栈）

先序：入栈根，循环"出栈访问 → 右孩子入栈 → 左孩子入栈"。

中序：一路向左入栈到底，出栈访问，再转向右子树。

## 五、由遍历序列构造二叉树

| 已知 | 能否唯一确定 |
| --- | --- |
| 先序 + 中序 | ✅ 能 |
| 后序 + 中序 | ✅ 能 |
| 层次 + 中序 | ✅ 能 |
| 先序 + 后序 | ❌ 不能（分不清左右子树） |

做法：先序第一个是根，在中序里找到根，左边是左子树、右边是右子树，递归。

## 六、线索二叉树

利用空的 `lchild` / `rchild` 存放**前驱/后继**指针：

- `ltag == 0` 表示指向左孩子，`1` 表示指向前驱
- 中序线索化后可以**不用栈**遍历

## 七、哈夫曼树

- **带权路径长度 WPL 最小**的二叉树
- 构造：每次取两个最小的权值合并，直到只剩一个
- 应用：哈夫曼编码（前缀码，频率高的编码短）
- 性质：没有度为 1 的结点

## 八、二叉排序树（BST）

- 左子树所有结点 < 根 < 右子树所有结点
- **中序遍历是有序序列**
- 查找/插入/删除平均 O(log n)，**最坏退化成链表 O(n)**
- 删除分三种：叶子直接删、只有一个孩子用孩子替代、有两个孩子用**中序后继（或前驱）**替代

## 九、平衡二叉树（AVL）

- 任意结点左右子树高度差 ≤ 1
- 失衡后有四种旋转：**LL、RR、LR、RL**
- 查找/插入/删除都是 O(log n)

> 红黑树是另一种平衡树，**插入删除旋转次数少**，C++ STL 的 map/set 用它。本科阶段了解概念即可。

## 十、易错点

1. 树的高度从 1 开始数，别和"边数"混；
2. `n0 = n2 + 1` 只对**二叉树**成立；
3. 完全二叉树用数组存，下标从 1 开始才能用 `2i` / `2i+1` 公式；
4. 先序+后序不能唯一确定树；
5. 删除 BST 结点时，两个孩子的情况要用后继替换，不能直接删。

## 十一、经典题

| 题目 | 思路 |
| --- | --- |
| 二叉树的最大深度 | 递归 `max(l,r)+1` |
| 判断平衡二叉树 | 后序，返回高度并检查 |
| 二叉树的层序遍历 | 队列，按层输出 |
| 最近公共祖先 | 递归或父指针 |
| 验证二叉搜索树 | 中序遍历递增 |
| 对称二叉树 | 递归比较左右 |
